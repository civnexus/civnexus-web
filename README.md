# Civ Nexus

A research and project-development initiative exploring better ways to live, organize, discover, and build. This interactive 2050 vision presents twelve imagined communities where people, AI, and the living world flourish together.

Contact: connect@civnexus.com

## Setup

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

The production site is emitted to `dist/`.

## Deploy with Vercel

Import this repository in Vercel. The included configuration uses the Vite build command and publishes `dist/`; no environment variables are required.
